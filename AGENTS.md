# AGENTS.md

This repository uses spec-driven development: each file and directory containing source code has a spec describing its business logic (`some-file.ext` → `some-file.SPEC.md`, `some-dir/` → `some-dir/SPEC.md`, starting at the root `SPEC.md`). Keep the SPEC.md files in sync with code changes.

Before modifying/creating SPEC.md files, you must always read and respect https://raw.githubusercontent.com/brillout/sdd/refs/heads/main/sdd.md
